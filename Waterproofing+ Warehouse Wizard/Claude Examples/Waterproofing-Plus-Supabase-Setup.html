Create your free database

This gives your app a shared "brain" so every phone sees the same live inventory, tools and trucks — while keeping the exact design you liked. About 10 minutes. No coding on your end.

You'll need two files I sent you:
  • waterproofing-plus-supabase-setup.sql — the script that builds your database, pre-filled with your real data.
  • (Later) the app file — I'll send the connected version once your database is up.

Think of Supabase as a free, secure filing cabinet in the cloud. Your app reads from and writes to it, so everyone shares one set of records.

1 Make a Supabase account & project

  1. Go to supabase.com and click Start your project (sign in with your Google account — one click).
  2. Click New project.
  3. Name it Waterproofing. It will ask you to create a database password — type any strong password and save it somewhere (you likely won't need it day-to-day, but keep it).
  4. Pick the region closest to you, then Create new project. Give it a minute or two to set up.

2 Build the tables (one paste)

  1. In your new project, look at the left sidebar and click SQL Editor.
  2. Click New query.
  3. Open waterproofing-plus-supabase-setup.sql on your computer, select all of it (Cmd/Ctrl + A), copy, and paste it into the big empty box.
  4. Click Run (bottom right). It should say Success.
💡 To confirm it worked: click Table Editor in the sidebar. You should see tables like materials, tools, trucks — open materials and you'll see all 45 of your real items. That means your data is live in the cloud. 🎉

If any line shows a red error, don't worry — copy the error text and send it to me, and I'll fix the script.

3 Grab the two values I need

These let the app talk to your database. Both are meant to live inside the app, so they're safe to share with me.

  1. In the sidebar, click the gear icon (Project Settings) at the bottom.
  2. Click API (or "API Keys").
  3. Copy these two things:
    • Project URL — looks like https://abcdxyz.supabase.co
    • anon public key — a long string labelled anon / public.
🛑 Important: on that same page you'll also see a service_role / secret key. Do NOT share that one — with anyone, ever. I only need the anon public key (the public one). If you're ever unsure which is which, just tell me the labels you see and I'll point to the right one.
